Формат и правила
Правила для кандидата:
• Можно всё: Claude Code, Cursor, Copilot, ChatGPT, документацию, Google.
• Экран расшарен целиком, включая чат с ИИ. Промпты — часть того, что мы смотрим.
• Думать вслух: зачем этот промпт, почему принял или отверг ответ.
• За каждую строку отвечает кандидат, а не ИИ. Интервьюер может ткнуть в любую строку и спросить «почему так».
• Не обязательно закончить всё. Важнее, чтобы сделанное было корректным.
• Запрещены async/await, actor, Task, AsyncStream. Разрешены GCD, OperationQueue, NSLock/os_unfair_lock, колбэки, Combine.
• Swift 5 language mode.
• UI можно на UIKit или SwiftUI, на выбор кандидата.
• Правила по ИИ те же: можно всё, экран и промпты открыты, за каждую строку отвечает кандидат.
Задача для кандидата: MessageOutbox
Реализуй очередь исходящих сообщений мессенджера: сообщения уходят на сервер через ненадёжную сеть, а UI показывает статус каждого.
Этап 1 — отправка и статусы
• enqueue(text:chatID:) -> OutgoingMessage возвращает сообщение сразу, до отправки. Метод вызывается с любого потока.
• Статусы: pending → sending → sent или failed. Изменения приходят подписчику на main thread.
• В рамках одного чата сообщения доходят до сервера строго по порядку. Разные чаты не блокируют друг друга.
• Простой экран: поле ввода и список сообщений одного чата со статусами.
Этап 2 — ненадёжная сеть
• Ретраи с exponential backoff и jitter, максимум 5 попыток, потом failed.
• Ручной «Повторить» для failed.
• Нет сети → пауза, сеть появилась → продолжает сама.
• Юнит-тесты на порядок и ретраи, без реального ожидания backoff.
